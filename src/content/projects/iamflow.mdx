<ProjectSection title="Abstract">
Autoregressive video generation is promising for long and interactive video synthesis, but long rollouts still suffer from memory degradation, identity drift, character duplication, and attribute loss. IAMFlow addresses this with a training-free identity-aware memory framework that explicitly models persistent entities and tracks their attributes across evolving prompts.
</ProjectSection>

<ProjectSection title="Highlights">
- Introduces identity-aware memory for long video generation, organizing historical evidence around persistent entity IDs instead of implicit frame or token similarity.
- Uses an LLM to extract entities and assign global IDs, then uses asynchronous VLM verification to refine visual attributes from generated frames.
- Adds a practical inference acceleration pipeline with asynchronous visual verification, adaptive prompt transition, and model quantization.
- Introduces NarraStream-Bench, a 324-script benchmark for narrative streaming video generation across visual quality, temporal consistency, and instruction compliance.
</ProjectSection>

<ProjectSection title="Method">
IAMFlow maintains a global entity registry, a frame archive, and an active identity-aware memory buffer. For each prompt, entities and visual attributes are parsed into persistent IDs; during generation, archived frames are scored and retrieved to cover the active identities; verified keyframes are then injected back into the autoregressive generation process as structured long-term memory.
</ProjectSection>

<ProjectSection title="Results">
Experiments on NarraStream-Bench show that IAMFlow achieves the best overall performance among the evaluated baselines, with especially strong gains on metrics that stress entity-state memory, boundary smoothness, conditional adjacent consistency, and conditional long-range consistency. The system also reports a 1.39x speedup over the most efficient baseline in the 60-second multi-prompt setting.
</ProjectSection>
